# プロジェクト保存と出力メタデータ

## プロジェクトを保存する

「ファイル → プロジェクトを保存」（Ctrl+S）で `.astrostacker` ファイルを保存します。
「プロジェクトを開く」（Ctrl+O）で再開できます。「名前を付けて保存」はCtrl+Shift+Sです。
ツールバーの「保存」は従来どおりスタック画像の書き出しです。

保存する内容:

- Light / Dark / Flat / Flat Dark / Biasの分類、画像一覧の順序、各画像の使用チェック
- 基準画像、位置合わせグループの履歴、現在の変換行列、残差・星数・品質評価・星カタログ
- Plate SolveのWCSと成功時の設定
- スタック方式、Sigma・反復回数、キャリブレーション設定、デベイヤータイミング、位置合わせ設定
- 移動天体の座標アンカー、対象天体、観測地点コード、時刻補正、移動天体の基準フレーム
- 選択中の画像、画像分類タブ、星表示、プレビュー設定、ズーム・スクロール位置
- 最後に自動保存したスタック結果の参照と、その結果の撮影条件集計
- 「ファイル → プロジェクトのメモ」で記入した自由文

元画像や大きな作業配列はプロジェクトに埋め込みません。画像パスは可能な限りプロジェクトからの相対パスで保存します。元画像とプロジェクトを同じフォルダ構成で移動すると復元できます。Windowsで別ドライブにある画像は絶対パスになる場合があります。

欠損した画像は一覧に残して使用を解除し、警告します。変更された画像は情報を読み直します。画像・基準画像・キャリブレーションの変更による不整合を避けるため、入力に変更・欠損があるプロジェクトでは位置合わせ行列を無効にします。位置合わせ設定や補正フレームの変更も再計算判定に含めます。

位置合わせ履歴の一覧は「ファイル → 位置合わせ履歴」で確認できます。復元する変換行列は各画像の最新のものです。過去の任意の時点に戻すUndo機能や、別形式のDSSプロジェクトの読み込みには対応していません。

プロジェクト保存は一時ファイルに書いてから置き換えます。書き込みに失敗しても元のプロジェクトを残します。未保存の変更がある状態で開き直す・リセットする・終了すると保存確認が出ます。

## 画像ごとの解析履歴

画像を読み込んだときや解析したとき、隣に `画像名.ARW.astrostacker.json` のような小さな履歴ファイルを自動作成します。画素データは保存せず、元画像も変更しません。

画像だけを開き直しても、次の情報を再利用できます。

- 読み込み済みの画像情報・EXIF
- Plate SolveのWCSと、同一設定での成功結果
- 星カタログ・品質評価・位置合わせ結果

ファイルのサイズ・更新時刻が変わった履歴は使いません。変換行列の再利用では基準画像・補正フレームも確認します。画像だけを再追加した場合、補正なしの同じ位置合わせグループと基準画像が揃っていれば、その位置合わせを採用します。補正フレームを含む作業の確実な再開にはプロジェクト保存を使ってください。

使用チェック・時刻の手動補正など作業ごとの選択はプロジェクトから復元します。履歴ファイルだけから再追加した画像は使用状態で追加します。書き込み禁止フォルダでは履歴保存をスキップしてログに記録し、画像処理は続けます。履歴ファイルが壊れていた場合は元画像を読み直します。

スタック用の巨大な一時ファイルや展開画像の永続キャッシュとは別の仕組みです。プロジェクトと履歴はバージョン付きJSONで、pickleは使用しません。

## スタック後のEXIF / FITSヘッダー

集計対象は、**実際にそのスタックに使ったLightフレームだけ**です。使用解除された画像と、位置合わせを使用するスタックで位置合わせに失敗した画像は除外します。集計は結果と一緒に保持し、後からチェックや設定を変えても過去の結果の撮影条件を再集計しません。

| 項目 | 保存する値 |
| --- | --- |
| ExposureTime / FITS EXPTIME | 使用フレームの既知の露出時間の合計（秒） |
| ISO | 使用フレームで最も多いISO |
| FNumber / FITS FNUMBER | 使用フレームで最も多いF値 |
| UserComment / FITS COMMENT | 個々のSS・ISO・F値と各枚数、方式、使用枚数、不明値の枚数 |

最頻値が同数なら、使用フレームの順序で先に出た値を採用します。不明値・不正な値は最頻値の集計から除外します。露出時間が不明な画像がある場合は既知分だけを合計し、その旨と不明枚数をコメントに残します。全て不明な項目は標準欄に書きません。

例: `30秒・ISO400・F2.8` が1枚、`60秒・ISO800・F4` が2枚なら、標準欄は **150秒・ISO800・F4**。コメントにはSS・ISO・F値の内訳を全て記録します。

FITSの自動保存と、FITS / TIFF / JPEG / PNGへの手動書き出しで同じ集計値を使います。画像保存ダイアログの「EXIFコメント」に自由文を入力すると集計コメントに追記します。JPEG・PNG・TIFFのUserCommentは日本語に対応します。FITSのヘッダーはASCII制約があるため、日本語や改行はエスケープ表現で記録します。EXIFを表示しない画像ビューアもあります。

FITSでは露出時間やWCSを文字列にせず数値で保存し、長いコメントも切り捨てません。恒星基準で位置合わせしてスタックした結果には、基準画像にある天球WCSを継承します。移動天体基準など、出力と元WCSの座標系が一致する保証がない場合はWCSを転記しません。元画像のMakerNoteなど全ての独自EXIFを丸ごと継承する機能ではありません。

TIFFは16bit整数／32bit浮動小数のRGBを維持したままEXIFを付加します。PNGの16bit RGB出力にもEXIFを付加します。TIFFはclassic TIFFのサイズ範囲を使用し、大きすぎる出力にはFITSを使用してください。
