# File Formats

## Overview
This document describes the file formats supported by Astro Stacker.

## Supported Input Formats
- FITS (.fits, .fit)
- TIFF (.tiff, .tif)
- PNG (.png)
- JPEG (.jpg, .jpeg)

## Output Formats
- FITS (.fits)
- TIFF (.tiff)
- PNG (.png)
